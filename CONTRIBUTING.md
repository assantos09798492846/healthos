# Contribuindo com o HealthOS

## Regras básicas

1. Criar uma branch para cada alteração.
2. Manter documentação e código atualizados em conjunto.
3. Não armazenar dados médicos reais, credenciais ou segredos no Git.
4. Registrar decisões arquiteturais relevantes em `docs/adr`.
5. Executar testes antes de abrir um Pull Request.
