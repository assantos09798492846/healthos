# HealthOS

Personal Health Intelligence Platform.

O HealthOS é uma plataforma pessoal de inteligência em saúde destinada a consolidar exames, histórico clínico, medicamentos, dados de dispositivos, indicadores, tendências e relatórios.

## Princípios

- O usuário é proprietário dos seus dados.
- Segurança e privacidade desde a concepção.
- Histórico clínico versionado e rastreável.
- IA como apoio, nunca como substituição do profissional de saúde.
- Arquitetura extensível para novos tipos de exames e dispositivos.
- Experiência multiplataforma: macOS, Windows, iOS, Android e Web.
- Compatibilidade progressiva com padrões como FHIR, LOINC, SNOMED CT e UCUM.

## Estrutura

- `apps/`: aplicações web, mobile e desktop.
- `services/`: serviços de API, autenticação, importação e análises.
- `packages/`: componentes e módulos compartilhados.
- `docs/`: documentação funcional, técnica, arquitetural e de UX.
- `database/`: modelos, migrações e dados de referência.
- `infrastructure/`: infraestrutura, containers e automações.
- `tests/`: estratégia e suites de testes.
