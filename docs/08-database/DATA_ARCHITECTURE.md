# Arquitetura de Dados

## Princípios
- Identificadores imutáveis.
- Versionamento de fatos clínicos.
- Proveniência obrigatória.
- Separação entre dado original, extraído e confirmado.
- Unidades normalizadas com preservação do valor original.
- Histórico de alterações.
