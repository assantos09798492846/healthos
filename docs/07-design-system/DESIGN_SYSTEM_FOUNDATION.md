# Design System — Foundation

- Escala de espaçamento baseada em 4 px.
- Tipografia responsiva e legível.
- Contraste WCAG 2.2 AA.
- Componentes semânticos para status clínico.
- Temas claro, escuro e sistema.
- Navegação por teclado.
- Estados: padrão, hover, focus, pressed, disabled, loading, error e success.
