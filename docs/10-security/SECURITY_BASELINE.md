# Baseline de Segurança

- Autenticação forte.
- MFA quando disponível.
- Menor privilégio.
- TLS.
- Criptografia em repouso.
- Segredos fora do código.
- Auditoria.
- Backups cifrados e testados.
- Proteção contra upload malicioso.
- Política de retenção.
- Exportação e exclusão conforme LGPD.
- Dados médicos reais proibidos no Git.
