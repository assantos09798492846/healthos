# Princípios de UX

- Clareza clínica antes de densidade.
- Reconhecimento em vez de memorização.
- Divulgação progressiva.
- Erros acionáveis.
- Cor nunca como único sinal.
- Linguagem acessível e não alarmista.
- Desktop-first para análise.
- Mobile-first para captura.
- WCAG 2.2 AA como baseline.
