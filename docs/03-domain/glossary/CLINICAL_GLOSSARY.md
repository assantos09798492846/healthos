# Glossário Clínico e Técnico

| Termo | Definição |
|---|---|
| DiagnosticReport | Conjunto organizado de resultados de um exame ou laudo |
| Observation | Resultado clínico individual, numérico, textual ou categórico |
| ReferenceRange | Intervalo de referência aplicável a uma observação |
| Provenance | Registro da origem e transformação do dado |
| ClinicalEvent | Evento relevante na história de saúde |
| Measurement | Medição produzida por dispositivo ou entrada manual |
| AIInsight | Inferência assistida, separada do fato clínico |
| Consent | Autorização explícita para finalidade e escopo definidos |
| DICOM Study | Estudo de imagem médica composto por séries e instâncias |
| LOINC | Vocabulário para identificação de exames e observações |
| SNOMED CT | Terminologia clínica de conceitos de saúde |
| UCUM | Padrão de unidades de medida |
| FHIR | Padrão de interoperabilidade de dados em saúde |
