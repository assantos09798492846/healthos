# HealthOS — Visão Geral do Domínio

## Objetivo

Definir o modelo de domínio do HealthOS como fonte normativa para banco de dados, APIs, UX, integrações, IA e testes.

## Princípios

- A pessoa é o centro do domínio.
- Todo dado clínico possui origem, data, contexto e versão.
- Fatos clínicos são separados de inferências.
- O sistema aceita novos tipos de exames sem alteração estrutural.
- Eventos clínicos são organizados em linha do tempo.
- Integrações externas entram por conectores isolados.
- Dados originais nunca são sobrescritos silenciosamente.

## Bounded Contexts

1. Identity
2. Health Profile
3. Clinical Record
4. Diagnostics
5. Documents
6. Medication
7. Timeline
8. Devices
9. Analytics
10. Reporting
11. Consent
12. Audit
13. AI Assistance
14. Notifications
15. Configuration
